# Winery Process Automation System

## Overview

This project was developed as part of my graduation thesis and focuses on the automation and monitoring of a winery production process.

The system was developed using **CODESYS**, with PLC programming implemented in **Structured Text (ST)**. A SCADA visualization was also developed to enable process monitoring and operator interaction.

## Main Features

- PLC-based process automation
- Structured Text (ST) programming
- SCADA process visualization
- Start/Stop process control
- Setpoint configuration and parameter adjustment
- Real-time process status monitoring
- Automated process sequence control

## Technologies

- CODESYS
- Structured Text (IEC 61131-3)
- PLC Programming
- SCADA
